# Niki와 대화 및 일기 요약

## 검증 결과 (2026-11-10)

- 기준 소스: 마지막 릴리즈 `v0.1.22` (`9ceef97`). 이후 CI 최적화 및 기존 Sign in with ChatGPT 구현은 복원 커밋 `a20c924`에서 되돌렸다.
- Windows에 설치된 공식 `codex-cli 0.167.0`의 app-server를 사용했다. 클라이언트 이름을 Niki로 지정했으며 공식 앱으로 가장하지 않았다.
- 별도 테스트 환경에서 사용자가 직접 기기 코드 로그인을 완료했다. `account/read`가 `chatgpt`, `free`를 반환했다.
- `gpt-6-luna`를 명시하고 다른 모델로의 대체를 금지한 실제 요청이 완료됐다. Node 검증 스크립트와 Niki의 Rust 연동 양쪽에서 한국어 예시 일기 요약에 성공했다.
- 이 결과는 해당 무료 계정의 현재 접근 권한을 확인한 것이다. 모든 무료 계정의 접근, 무제한 사용, 향후 정책을 보장하지 않는다.
- 실제 일기는 테스트에 사용하지 않았다. 테스트용 로그인은 공식 `account/logout`으로 해제했고 임시 `auth.json` 제거를 확인했다. 기존 Codex 로그인은 변경하지 않았다.
- Windows 자격 증명 저장소를 사용하는 별도 테스트에서 더미 자격 증명을 저장하고 새 프로세스에서 읽은 뒤 삭제했다. 평문 `auth.json`이 생성되지 않음을 확인했다. macOS 실기기 검증은 아직 하지 않았다.

## 사용 방법

1. 공식 Codex를 설치한다. 현재 확인한 CLI 버전은 0.167.0이다.
2. Niki의 **설정 → Niki와 대화 → ChatGPT 계정으로 연결**을 선택한다.
3. 표시된 공식 인증 페이지에서 로그인하고 일회용 코드를 입력한다.
4. 일기 상단의 **별 세 개 AI 아이콘**으로 오른쪽 **Niki와 대화** 사이드바를 여닫는다. 제목 아래 **요약**을 누르면 현재 열린 일기를 저장한 뒤 요약을 대화에 추가한다.
5. 하단 입력창에서 메시지를 보내면 최근 대화를 참고해 Niki가 답한다. 일기가 열려 있지 않아도 대화할 수 있으며 이때 요약 버튼만 비활성화된다.

일기를 연 뒤 로그인한 경우에도 로그인 대기 상태 및 앱으로 돌아오는 시점에 연결을 다시 확인한다. 연결이 해제되면 버튼과 사이드바를 숨긴다. 대화창은 상단 메뉴바 아래 오른쪽에 일기장 레이아웃을 바꾸지 않고 위에 겹쳐 나타나는 너비 435px(좁은 창에서는 창 너비 이내)의 오버레이이며, ease-in-out 슬라이드로 열고 닫는다. 열기 버튼은 화면 오른쪽 아래 플로팅 버튼이고 상단 메뉴바에는 없다. Niki는 상냥한 상담가의 말투로 고정되어 일기의 과거 기록을 근거로 위로와 방향을 제시한다. 대화할 때 Niki는 계층형 기억을 사용한다: 최근 일기 최대 14편 전문, 메시지와 관련된 일기 최대 6편 전문, 월별 개요, 더 오래된 일기의 앞부분(240자)을 함께 전송한다. 관련 일기는 이 기기에서 찾는다.

- **검색 모델**: GPT 계정이 연결된 것을 앱이 처음 확인하면(Codex 상태 확인 시) 모델이 없을 때 백그라운드에서 한국어 문장 임베딩 모델 `jhgan/ko-sroberta-multitask`(int8 ONNX, 약 112MB, 리비전·크기·SHA-256 고정)를 Hugging Face에서 자동으로 받아 앱 데이터 폴더의 `models/`에 저장한다. 버튼은 없고, 받는 동안 대화창에 진행률만 보인다. 실패하면 대화창이 열려 있는 동안 1분에 한 번 다시 시도하며, 그동안 대화는 아래 키워드 검색 방식으로 동작한다. 모델은 앱 업데이트 후에도 남으므로 한 번만 받으며, GPT 연결을 쓰지 않는 사용자는 받지 않는다(설치 파일에 넣지 않은 이유: 업데이트마다 설치 파일 전체를 다시 받으므로 매번 112MB가 늘고, 라이선스가 명시되지 않은 모델을 재배포하게 된다). 추론은 순수 Rust(`tract`)로 실행해 Windows·Apple Silicon·인텔 Mac에서 같은 방식으로 동작하며, 일기는 검색을 위해 외부로 보내지 않는다. 일기를 약 150자 조각으로 나눠 벡터를 `vectors.bin`에 저장하고, 일기가 바뀌면(`updated_at`) 그 일기만 다시 계산한다. 색인은 대화창을 열거나 답장을 받은 뒤 백그라운드에서 약 2초씩 진행하고, 메시지를 보낼 때 남은 변경분을 최대 약 2초 동안 먼저 반영한다. 검색은 의미 유사도(가장 높은 점수와 0.025 이내의 상위 8편)와 한글 2글자 조각 키워드 점수를 RRF로 합치고, 메시지에 '작년', '3월' 같은 기간이 있으면 그 기간 일기를 앞에 둔다. 한국어 일기 12편·의미 질문 12개 비교에서 이 모델은 12/12, multilingual-e5-small은 8/12, bge-m3(약 570MB)는 11/12였다.
- **검색 모델이 준비되기 전**: 일기가 최근 원문 한도를 넘으면 답변 전에 메시지·직전 질문·일기 기간·월별 개요만 담은 짧은 "검색 계획" 요청을 보내 검색어와 기간(최대 3개)을 받아 로컬 키워드 검색에 쓴다. Codex의 동적 도구(`dynamicTools`)는 코드 모드 호스트를 켜야 동작하고 그러면 모델이 앱이 감시하지 못하는 JavaScript 실행 도구를 쓸 수 있어 사용하지 않는다.
- **Codex가 하는 백그라운드 작업**: 일기별 요약은 만들지 않는다. 대화가 길어지면 오래된 메시지(최근 약 6천 토큰 제외, 3천 토큰 이상 쌓였을 때)를 약 9천 토큰씩 누적 요약으로 합치고, 지난 달 중 일기가 2편 이상인 달마다 일기 앞부분(600자)으로 3~5문장 월별 개요를 만든다. 둘 다 `journal.json`에 저장하며 일기가 바뀌면 그 달 개요만 다시 만든다. 메시지를 보내면 진행 중인 단계가 끝난 뒤 정리를 멈추고 대화를 먼저 처리한다.
- 전송량 예산은 추정 토큰(ASCII 4글자 ≈ 1토큰, 한글·CJK 1글자 ≈ 1토큰) 기준이다: 최근 일기 1만, 관련 일기 8천(검색 계획 사용 시 1.2만), 월별 개요 5천, 오래된 일기 앞부분 7천, 대화 8천.
- 요약 캐시·대화 요약은 백업 내보내기에서 제외되고, 검색 모델과 색인은 일기에서 다시 만들 수 있는 기기 전용 데이터라 동기화·백업하지 않는다. 일기 요약 버튼은 지금처럼 현재 일기만 전송한다. 대화와 작성 중인 메시지는 패널을 여닫거나 일기장을 이동해도 유지된다. 전송한 대화는 Niki의 로컬 저장 파일에 기록되어 앱을 다시 실행해도 복원된다. 전송하지 않은 입력 초안은 앱 실행 중에만 유지된다.

사용 가능 여부와 한도는 연결한 계정에 따른다. 계정 권한 오류, 사용 한도, 연결 실패는 화면에 표시하며 다른 모델이나 API 요금제로 자동 전환하지 않는다. Codex는 별도 설치가 필요하며 Niki가 자동으로 다운로드하거나 설치하지 않는다.

## 인증과 데이터 경계

- Niki 데이터 폴더 아래 별도 `codex` 홈을 사용한다. 사용자의 기본 Codex 로그인 파일을 읽거나 복사하지 않는다.
- 공식 `account/login/start`의 `chatgptDeviceCode` 방식으로 인증하고 `cli_auth_credentials_store="keyring"`을 강제한다. OS 자격 증명 저장소가 실패하면 연결을 실패 처리하며 평문 저장으로 전환하지 않는다.
- 액세스 토큰과 리프레시 토큰은 Codex가 관리한다. Niki의 프런트엔드, 일기 저장 파일, 백업, Drive 동기화로 전달하지 않는다. 연결 상태는 연결 여부와 플랜만 반환한다.
- 실행 파일은 설치 경로 또는 절대 PATH 디렉터리에서 찾으며 셸 문자열로 실행하지 않는다. Windows 하위 프로세스에는 창 숨김 옵션을 적용한다.
- 요약 요청은 앱이 잠기지 않은 상태에서만 가능하다. 서버에서 선택한 일기를 조회해 삭제 여부, 최신 버전, 빈 내용, 60 KB 제한을 검사한다. 편집 저장이 실패하면 전송하지 않는다.
- OpenAI에 보내는 일기 데이터는 선택한 일기의 제목과 본문이다. 본문에 작성한 링크/이미지 참조 문자열은 포함될 수 있으나 링크를 방문하거나 첨부 파일 내용을 읽지 않는다. 일기장 이름, 별명, 태그, 위치 필드, 다른 일기, 첨부 바이너리는 전달하지 않는다.
- 일반 메시지에는 입력한 내용과 최근 대화의 역할·내용을 함께 보낸다. 전달할 문맥은 내용 기준 최대 60 KB이며 이전 기록은 로컬에서 삭제하지 않는다. 현재 일기 원문을 일반 메시지에 자동 첨부하지 않는다. 대화 기록은 모든 일기장에서 공통으로 사용하며 Drive 동기화 및 일기 백업에는 포함하지 않는다.
- 요청마다 별도 app-server 프로세스와 임시 대화를 사용한다. Codex 자체의 로컬 대화 기록, 분석 텔레메트리, 프롬프트 로깅을 끄고 셸·컴퓨터 조작·파일 변경·웹·플러그인·기억·다중 에이전트 기능을 비활성화한다. 프로젝트/호스트 스킬도 자동으로 넣지 않는다.
- 서버가 Niki에 도구 실행을 요청하면 거절한다. 읽기 전용 샌드박스와 시간/응답 크기 제한을 적용한다. 요청 종료 시 하위 프로세스를 종료한다.
- 요약과 답변은 텍스트로만 렌더링하고 HTML로 실행하지 않는다. 일기 원문에 자동 반영하거나 localStorage에 저장하지 않는다. 다른 일기로 이동하거나 패널을 닫아도 응답은 공통 대화에 추가된다. 앱이 잠겨 있으면 대화를 읽거나 쓰지 않으며 응답 표시를 중단한다.
- 상위 서버의 원시 오류는 프롬프트나 인증 정보를 포함할 수 있으므로 사용자에게 그대로 노출하거나 로그에 기록하지 않는다.
- 테스트 산출물 디렉터리 `output/`은 Git에서 제외한다. 테스트에는 가상 일기만 사용한다.

## 검증 명령

```powershell
npm run build
npm test
cargo test --locked
```

실제 계정 테스트는 기본 테스트에서 제외한다. 명시적으로 분리된 무료 계정 테스트 홈을 준비한 경우에만 실행한다. 테스트는 완료 후 해당 테스트 홈에서 로그아웃한다.

```powershell
$env:NIKI_CODEX_TEST_HOME = Join-Path (Get-Location) 'output/codex-free-verification/home'
cargo test --locked codex::tests::live_free_account_summary -- --ignored --nocapture
cargo test --locked codex::tests::live_keyring_storage -- --ignored
```
