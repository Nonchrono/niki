# 니키 대화·기억 동기화

v0.1.32부터 같은 Google Drive 계정에 연결한 기기 사이에서 다음 데이터를 동기화합니다.

- 대화 메시지와 참고한 일기 링크
- 긴 대화 요약과 월별 일기 요약
- 일기 검색 벡터와 원본·모델 버전 정보
- AI에게 숨긴 일기장 선택

각 기기를 v0.1.32 이상으로 업데이트하고 같은 Google Drive 계정에 연결해야 합니다. ChatGPT 로그인과 일기 전송 동의는 기기마다 설정합니다. 로그인 정보, 실행 파일 경로, 검색 모델 파일은 동기화하지 않습니다. 검색 모델은 각 기기에서 자동으로 한 번 내려받습니다.

대화·검색·요약 변경 후에는 기존 자동 동기화가 실행됩니다. 앱 시작, 대화창 열기, 앱으로 돌아오기, 네트워크 복구 때도 확인하며, 앱이 실행 중이면 주기적으로 동기화합니다. 오프라인 변경은 로컬에 저장했다가 다시 연결되면 전송합니다. 수동 동기화 버튼도 동일하게 사용할 수 있습니다.

## 저장과 병합

기존 암호화 Drive 리비전의 선택 필드 `ai`에 변경된 항목만 실어 보냅니다. 업로드 전에 동일 리비전을 로컬 큐에 저장하므로 업로드 후 저장 실패 시에도 중복 메시지를 만들지 않고 재시도합니다. 암호화 키는 기존 일기 동기화와 같이 같은 Google 계정의 앱 데이터 폴더에서 관리합니다.

항목은 기기별 논리 시계와 식별자로 버전을 매깁니다. 기기의 실제 시각 차이에 의존하지 않습니다. 동시에 추가한 대화는 모두 보존하며, 답변은 질문과 묶어 정렬합니다. 메시지 삭제 표식은 이전 메시지보다 우선합니다. 삭제 시 다른 기기에서 아직 받지 못한 새 대화까지 지우지는 않습니다. 삭제된 질문에 늦게 도착한 답변도 되살리지 않습니다.

요약·검색 데이터는 항목별 버전으로 병합합니다. 대화 요약은 요약한 메시지 구간의 서명이 일치할 때만 사용하고, 월별 요약과 검색 데이터도 현재 일기에 맞는지 검사합니다. 검색 벡터의 모델 버전·내용 서명이 다르면 해당 기기에서 다시 준비합니다. 검색 데이터 초기화와 요약 삭제는 다른 기기에도 반영됩니다.

## 호환성과 검증

기존 로컬 대화·기억·검색 파일은 처음 실행할 때 옮깁니다. 이전 일기 동기화 형식은 계속 읽을 수 있지만 구버전 앱은 새 AI 동기화 데이터를 사용하지 못합니다. 일기 JSON 백업은 기존과 같이 일기·첨부 중심이며 AI 기록 복원은 Drive 동기화를 사용합니다.

업데이트 후 첫 동기화에서는 구버전이 이미 읽었다고 기록한 파일의 AI 필드도 다시 확인합니다. 기존 일기 리비전은 재적용하지 않으므로 그 사이의 오프라인 편집을 유지합니다.

자동 테스트는 두 기기의 동시 추가·삭제, 새 기기 복원, 암호화 전송, 업로드 후 체크포인트 실패 재시도, 오래된 벡터·잘못된 데이터 거부, 동기화 중 답변 취소와 화면 갱신을 확인합니다. 실제 사용자의 계정이나 대화는 테스트에 사용하지 않습니다.
